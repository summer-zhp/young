# 打工人治愈所 - 微信小程序

当代打工人在工作间隙和下班后缺乏快速、轻量级的放松方式，需要一款**随时随地、即刻治愈**的小程序，提供心灵鸡汤式的温暖和专注工作时的陪伴。

## 功能模块

### 🌿 治愈
- 每日治愈内容
- 心灵鸡汤

### 🎮 放松室
- **树洞** - 陪伴者倾诉功能，有心事时随时倾诉，获得温暖回应
- 专注时钟 - 番茄工作法时钟，专注工作学习
- 戳泡泡 - 解压小游戏

### 👤 我的
- 个人中心
- 收藏内容

## 新增功能：树洞陪伴者

### 功能说明
在放松室新增「树洞」入口，用户可以：
- 倾诉烦恼、分享心情
- 获得温暖、共情的回应
- 在需要时得到简单实用的建议

### 设计理念
- **不出现 AI/智能字眼** - 以"树洞"命名，打造真实陪伴感
- **善于倾听** - 首先是一个耐心的倾听者
- **适度建议** - 在适当时机给出简单实用的建议
- **温暖共情** - 像一位贴心的朋友

### 技术实现
- **微信云开发 AI SDK**: 使用 `wx.cloud.extend.AI.createModel()` 和 `streamText()` 直接调用混元模型
- **System Prompt**: 在调用时传入系统提示词，定义"小树洞"陪伴者角色
- **前端页面**: `pages/treeHole/treeHole` - 聊天对话界面
- **入口位置**: 放松室页面第一个工具卡片（高亮显示）

## 部署说明

### 1. 开通云开发 AI 能力
首次使用 AI 功能需要在云开发控制台开通：
1. 打开微信开发者工具 → 云开发控制台
2. 进入「AI 模型」板块
3. 确认已开通 AI 模型调用权限

### 2. 预览小程序
在微信开发者工具中点击「预览」即可看到最新效果。

## 开发记录

### v1.3.1 - 树洞页面精美设计优化
- 采用柔和治愈系设计风格（Soft Healing）
- 渐变背景 + 浮动装饰光晕效果
- 半透明毛玻璃输入框
- 欢迎头像带呼吸光晕动画
- 消息气泡优雅弹跳入场动画
- 加载时打字机圆点指示器
- 使用 TDesign 组件库图标
- 头部透明背景，自然融合小程序导航栏

### v1.3.0 - 使用微信云开发 AI SDK 调用混元模型
- 使用 `wx.cloud.extend.AI.createModel()` 创建模型实例
- 使用 `streamText()` 方法进行流式调用
- 在调用时传入 `system` 角色的消息，定义"小树洞"角色
- 不再依赖 CloudBase Agent，直接调用 AI 模型
- 支持流式响应，实时显示 AI 回复

### v1.2.0 - 使用 CloudBase Agent 重构
- 接入微信云开发 AI Agent 能力
- 使用 `cloud.extend.AI.bot.sendMessage()` 接口
- 支持流式响应和思维链内容处理
- 通过 threadId 管理对话连续性

### v1.1.0 - 新增树洞陪伴者功能
- 创建 `treeHole` 云函数，调用混元 AI 模型
- 新增 `pages/treeHole` 倾诉对话页面
- 在放松室添加树洞入口（高亮显示）
- 优化对话界面样式和交互体验

### v1.0.0 - 初始版本
- 基础治愈内容展示
- 专注时钟功能
- 戳泡泡小游戏
- 用户收藏功能
